# FastFsm.Net (legacy metapackage)

This package ID is kept for projects that still reference `FastFsm.Net` (including **0.6.9.x** on NuGet.org).

It does not contain libraries or analyzers. It adds a NuGet dependency on **[FastFsm.Sharp](https://www.nuget.org/packages/FastFsm.Sharp)** at the same version.

**New projects:** use `FastFsm.Sharp` directly.

Your C# code (`Abstractions.*`, `FastFsm.*`) is unchanged.
